Impostazioni ⚙

Backup JSON

Esporta tutti gli appunti, compresi disegni e fotografie.

Importa JSON

Legge anche i backup del prototipo precedente. Le note con lo stesso ID vengono aggiornate.

Promemoria nel calendario

Esporta eventi .ics per importarli nel calendario Android, che potrà notificarti anche con Onfim chiusa.

Notifiche web

Richiedi il permesso del browser. Gli avvisi locali di Onfim non sono garantiti a pagina chiusa.

Riservatezza

Il PIN nasconde gli appunti riservati agli sguardi indiscreti, ma non cifra i dati. Chi accede ai dati del browser può aggirarlo.

Imposta / modifica PIN

Serve per aprire e visualizzare gli appunti riservati.

Blocca ora

Nasconde nuovamente gli appunti riservati.

Archiviazione

Gli appunti vengono salvati automaticamente nel database IndexedDB del browser. Non ci sono account, server o sincronizzazione.

Un JSON di backup non può essere sovrascritto automaticamente nella cartella Download o su Drive da un normale HTML su Android. Usa Esporta per salvarne una copia aggiornata. Non cancellare i dati del browser senza un backup.

Se passi dall'HTML locale alla PWA pubblicata su GitHub Pages, importa il backup nella PWA: i due ambienti non condividono automaticamente i dati.
