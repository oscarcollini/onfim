ONFIM Lite PWA 0.8.18

Installazione: estrarre tutti i file del presente ZIP nella stessa
cartella del sito GitHub Pages, sostituendo quelli della versione precedente.
NON cancellare i dati del sito / browser e NON cambiare l'ID del manifest:
le note restano nel database locale del browser.

NOVITÀ:
- nella panoramica, fino a tre etichette seguite da +N per le altre;
- ricerca visibile in linea con Appunti, Preferiti, Archivio;
- ricerca anche nei NOMI dei file esterni collegati e degli audio allegati;
- nella sola lettura della nota aperta (anche composta), fotografie
  sfogliabili orizzontalmente con contatore e frecce; annotazioni mantenute;
- nessuna modifica a editor, miniature Home o HTML condiviso;
- Dati e backup riorganizzati: salvataggio, copie interne, export/import;
- nuove copie interne PWA con raccolte e impostazioni dei promemoria.
  Le copie vecchie senza questi campi restano ripristinabili.

AVVERTENZE:
- i backup interni risiedono nel browser e NON sopravvivono alla
  cancellazione dei dati del sito. Scaricare periodicamente un JSON.
- il ripristino di una copia interna sostituisce le note; importare
  un JSON aggiunge o aggiorna le note secondo l'ID.
- i JSON non sono cifrati e comprendono l'Archivio; non includono i
  file esterni collegati.
- la Lite NON integra OCR, geofence nativo, widget o backup cloud
  automatico; sono funzionalità della versione Android completa.

Controllare dopo aggiornamento: note e raccolte esistenti, ricerca,
foto in lettura, caricamento offline e gestione backup.
