onfim Lite 0.9.15 — PWA GitHub, build 9155

App per appunti con checklist, etichette, raccolte, foto annotate e
backup locale. La PWA si apre da https://oscarcollini.github.io/onfim/.

Prima di aggiornare, esporta un backup JSON e conservalo fuori dal browser.
Per pubblicare un aggiornamento dell’app, carica i file nella stessa
cartella di GitHub Pages. Mantieni lo stesso indirizzo per ritrovare
gli appunti. Dopo il caricamento, riapri l’app e controlla il colophon.

La build 9155 introduce il comando di installazione PWA. Se il browser
non mostra la richiesta, usa il menu del browser.
La PWA e l’APK Android usano archivi locali distinti. Per trasferire gli
appunti fra le due edizioni, usa il backup JSON.

Cache della PWA: onfim-shell-lite-v0.9.15-b9155.
