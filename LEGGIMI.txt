ONFIM LITE PWA 0.9.5 — Release completa per GitHub Pages
============================================================

Sovrascrivere i dieci file esistenti nella root del repository GitHub
(oscarcollini/onfim). Non creare una sottocartella e non pubblicare
vecchi ZIP o APK fra i file della PWA. Il solo README distribuito
resta questo LEGGIMI.txt.

Base PWA: 0.9.1. Le versioni .2, .3 e .4 sono state solo Android.
La memoria e il formato dei backup non cambiano.

NOVITÀ 0.9.5
- Ripetizione settimanale: etichetta dinamica dal giorno effettivo
  della scadenza scelta, anche in inglese. Non cambia il calcolo.
- Riferimenti data: @gg.mm.aaaa e @gg.mm.aaaa-oo:mm sono ora
  riconosciuti come @gg/mm/aaaa e @gg/mm/aaaa-oo:mm. Formati
  mescolati (es. 29/10.2026) e formato USA non sono accettati.
- Nelle Informazioni rimosso il riferimento all'OCR dell'APK,
  eliminato nel progetto Android 0.9.4.
- In Informazioni: Scarica APK apre una URL permanente di GitHub Releases:
  https://github.com/oscarcollini/onfim/releases/latest/download/onfim.apk
  Funzionerà soltanto dopo la prima Release GitHub con file onfim.apk.
- Verifica di traduzioni e testi. Nessun cambiamento ad aree di tocco,
  miniature, formattazione, note, promemoria o backup.

ATTENZIONE
- I promemoria PWA a programma chiuso non sono garantiti.
- Prima dell'aggiornamento, esportare un backup JSON esterno.
- Assicurarsi che l'installazione PWA aggiorni la cache versione 0.9.5.
